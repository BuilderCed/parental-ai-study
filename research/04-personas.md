## Executive Summary

### Insight Clé
La charge mentale parentale n'est **pas une problématique de tâches** (qui fragmentent déjà les apps), mais une problématique de **charge cognitive invisible** (anticipation, décision-making, équité couple). Les personas cibles sont celles pour lesquelles cette invisibilité crée une friction maximale.

### 4 Personas Principaux (MVP)
1. **Sophie** (Mère active CSP+, 2-3 enfants, couple) — Pain: asymétrie couple + burnout anticipé
2. **Karim** (Père impliqué, ne voit pas) — Pain: culpabilité + désir équité (mais pas vu comment)
3. **Nadia** (Mère solo, freelance, 1 enfant) — Pain: isolement décisionnel + burden total
4. **Aminata** (Mère diaspora, double réseau, 2 enfants) — Pain: coordination interculturelle + culpabilité absence

### 3 Personas Secondaires
5. **Claire & Thomas** (Couple recomposé, 3 enfants, 2 foyers) — Pain: synchronisation foyers + culpabilité ex
6. **Marc** (Père, enfant handicapé, 2 autres enfants) — Pain: stress santé + tâches multiplexes
7. **Valérie & Hugo** (Primo-parents, enfant unique, modèle-perfectionniste) — Pain: paralysie décision + overparenting

### Verdict Segmentation
**Cible MVP** : Sophie + Karim (couple en tension) + Nadia (solo en survival) = 65% du TAM initial.  
**Expansion Y2** : Aminata (diaspora), Marc (handicap), Claire & Thomas (recomposé).  
**Not MVP** : Valérie & Hugo (audience trop perfectionniste = peut créer toxicité app).

## Framework de Segmentation

### 3 Axes Principaux Identifiés

```
AXE 1: STRUCTURE FAMILIALE
├─ Couple (théoriquement 50-50)
├─ Solo parent (100% sur une personne)
├─ Recomposé (2+ foyers à gérer)
└─ Diaspora (réseau élargi, décalages géog)

AXE 2: CHARGE MENTALE PERÇUE (critère PRIMARY)
├─ "Je pense à tout" (>80% des tâches invisibles)
├─ "Je dois demander" (partenaire n'anticipe pas)
├─ "Seul(e) à décider" (aucun co-responsable)
└─ "Personne ne voit mon effort" (reconnaissance zéro)

AXE 3: RAPPORT À LA TECHNOLOGIE
├─ App-savvy / app-fatigued (millénniales CSP+)
├─ Pragmatique / résistant (Gen X, couples)
├─ Mobile-only (parents monoparentaux, low-income)
└─ Tech-anxious (peur écran, RGPD concerns)
```

### Segmentation Secondaire (Confirmée par données INSEE)

| Critère | Impact sur Persona |
|---------|------------------|
| **Âge des enfants** | 0-3 ans (imprévisibilité max), 6-12 ans (logistics max) |
| **CSP** | CSP+ = stress + perfectionnisme ; tous = survival mode |
| **Urbain/Rural** | Urbain = transport + horaires ; rural = distance |
| **Situation emploi** | 2 temps pleins (asymétrie max), 1 TP + 1 TP (+ précarité) |
| **Support réseau** | Famille proche (load partagée) vs isolé (load total) |
| **Génération mère** | Gen X (sceptical tech) vs Millennial (app-native) |

#### Journée Type (Lundi - Jour "chargé")

#### Top 3 Douleurs Quotidiennes

**Douleur #1: "Je pense à tout, toujours" (Intensité 9/10)**
- Anticipation 24/7 : repas, RDV, permissions, saisons, anniversaires camarades
- Verbatim : *"C'est moi qui retiens 100 petites choses. Mon mari ? Il 'aide' si je dis quoi faire. Je dois être le disque dur familial."*
- Symptôme : Fatigue cognitive maximale vers 19h (syndrome du "brain fog parental")
- Fréquence : Quotidienne, pire le dimanche soir (planification semaine = 2h mental)

**Douleur #2: "Fallait demander" — Asymétrie couple (Intensité 8/10)**
- Julien voit tâches visibles (cuisine, dodo) mais pas invisibles (qu'acheter, qui demande permission)
- Perception gap : Julien pense = 50-50 ; Sophie ressent = 70-30
- Verbatim : *"Il faut que je demande. 'Peux-tu vérifier le lunch de Lucas ?' Pourquoi ne voit-il pas que c'est à faire ?"*
- Conséquence : Friction couple augmente, intimité baisse (elle "vidée"), resentment silencieux
- Fréquence : Tous les 2-3 jours, escalade semaines de stress

**Douleur #3: Decision Fatigue + Culpabilité (Intensité 7.5/10)**
- Trop de micro-décisions (snacks, vêtements, activités, repas)
- Culpabilité : "Je fais pas assez" malgré 60+ heure/semaine (travail + famille)
- Verbatim : *"Même si je fais tout 'bien', j'ai l'impression de rater quelque chose. Les autres mères semblent plus sereine."*
- Signal de burnout montant : fatigue physique + émotionnelle, perte patience avec enfants
- Fréquence : Constante, exacerbée jeudi-dimanche

**Insight clé** : Sophie utilise ChatGPT secrètement pour anticipation (menus, emails). L'app idéale = formalisée version de ce qu'elle fait déjà.

#### Rapport à la Technologie
- **Digital literacy** : Haute (travail tech, utilise 8+ apps quotidien)
- **App fatigue** : OUI (trop d'apps, notifications cacophony)
- **Openness à IA** : FORTE (déjà utilise ChatGPT pour décisions)
- **Privacy concerns** : Moyen-haut (RGPD awareness, but pragmatic)
- **Device preference** : iPhone + Apple Watch (notifications)
- **Time spent on family apps** : 5-8 min/jour (max tolerance)

#### "Aha Moment" — Ce qui la ferait Adopter

**Scenario 1** : App qui dit "Semaine du 23 mars (dimanche 5pm) : 8 RDV + 12 tâches anticipation + 3 menus à préparer. Voici priority + qui peut faire quoi."

- **Impact** : Réduit cognitive load de 40%, crée visibilité couple (Julien voit enfin charge)
- **Adoption likelihood** : 85%

**Scenario 2** : Notification Smart dimanche 18h : "Semaine chargée : Sophie 8/10 load, Julien 3/10. Pour équité, Julien pourrait + anticiper. Ici 3 tâches invisibles he could own."

- **Impact** : Dépersonnalise feedback (c'est l'app qui parle, pas elle), crée conversation couple positive
- **Adoption likelihood** : 75%

**Scenario 3** : "ChatGPT intégré": Tape "2 enfants, pas viande lundi, 20 min de prép, budget €8" → suggère 3 menus + liste courses auto-remplie.

- **Impact** : Réduit friction d'une tâche quotidienne majeure (repas)
- **Adoption likelihood** : 90%

#### Willingness to Pay
- **Perception de valeur** : TRÈS HAUTE (si résout charge mentale réelle)
- **Price point** : €9.99/mois (Premium) = "coûte moins qu'un café/jour"
- **Max WTP** : €19.99/mois (si includes coupler features + analytics)
- **Freemium tolerance** : Faible (CSP+ préfère pay-once, friction réduite)
- **Trigger abandon** : Prix > €25/mois OU nécessite entrée données (friction revient)

#### Canaux de Découverte Préférés
1. **Recommandation amie** (bouche-à-oreille) — 45% likelihood d'adoption
2. **Podcast parenting / newsletter** (type Mère-grand, Les Décodeuses) — 35%
3. **Publicité Instagram** (ciblée CSP+ parents) — 25%
4. **Review App Store** (rubrique "family organization") — 20%
5. **NOT: Reddit/forums** (Sophie n'a pas le temps lurking)

#### Citation Emblématique

> *"Je veux une IA qui regarde mon semaine et me dit : 'Voici ce qui arrive, voici ce que tu dois anticiper, et voici où tu peux demander l'aide à Julien.' Pas une app de plus que je dois activer. Juste une assistante discrète qui voit tout."*

#### Photo Description (pour maquettes)
Sophie, 36 ans, cheveux châtain clair attachés (mom-bun), vêtue casual-professionnel (chemise + jean), sourire fatigué, iPhone en main, regard qui "scanne" mentalement l'environnement. ## Différences Culturelles France-Spécifiques

### System français unique impacts on Parenting Load

#### 1. **Système scolaire français**
- **Cantine obligatoire** (vs packing lunch daily) = reduces daily logistics
- **Horaires scolaires** (8h30-16h30 mostly) = predictable
- **Créche publique** (subsidized via CAF) = more affordable than US
- **BUT** : Permissions system = more admin than some countries
- **Implication** : Anticiaptation calendars need to map French school calendar exactly

#### 2. **CAF & Allocations familiales**
- **CAF = huge load reducer** (subvention crèche, aide parents isolés, allocations)
- **BUT** : Admin load to manage (declarations, re-evaluations)
- **Apps should integrate** : CAF calendar (re-evaluation dates), aid calculator

#### 3. **French work culture**
- **Congé parental** (3 ans max, partageable 50-50) = policy supports equality
- **BUT** : Cultural expectation = mère stay home (even if can't afford)
- **Work schedule** : 35h legally, but CSP+ often 45h+ (underpaid overtime culture)
- **Implication** : App needs to show that "both parents working" is reality, not exception

#### 4. **Healthcare system (Ameli)**
- **PMI** (Protection Maternelle Infantile) = free health checks for kids 0-3
- **Médecins généralists** (vs pediatrics) = more coordination needed
- **Doctolib integration** = critical for French adoption
- **Implication** : App should sync with Doctolib, show PMI dates

#### 5. **Laïcité / Religious freedom paradox**
- **French schools** = officially secular (no religious symbols)
- **BUT** : Diaspora families (like Aminata) juggle both
- **Implication** : App should support bilingual, bicultural without judgment (not France-only design)

#### 6. **Divorce law & co-parenting**
- **France** : 50-50 custody increasingly standard (not automatic to mère)
- **BUT** : Logistics = doubled (two homes, two schedules)
- **Implication** : App needs multi-household view for recomposé families
