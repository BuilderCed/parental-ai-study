## 🔑 Key Takeaways by Role

### Pour le CEO/Founder :
- **Market Opportunity** : Gap non capturé (anticipation + charge mentale visible + équité couple)
- **Archetype** : EVERYMAN + SAGE = gagnant (pas Hero/Caregiver/Ruler)
- **Naming** : RESPIRE (émotionnel, mémorable, FR+EN)
- **Timeline** : Window de 12-18 mois avant que concurrents copient

### Pour le Product Manager :
- **Avoid 6 pièges** : Culpabilisation, surveillance couple, dépendance IA, infantilisation, comparaison sociale, méfiance tech
- **Core Promise** : "Anticipe la semaine + rend visible la charge + construit équité"
- **Success Metric** : "Wow moment" dans les 7 premiers jours
- **Roadmap** : Beta → Community → Partnerships

### Pour le Marketing :
- **Tagline** : "Pour que tu ne penses pas à tout"
- **Messaging** : Différent par persona (Mère Active / Père Impliqué / Parent Solo)
- **Channel** : WhatsApp/SMS-first (anti-app-fatigue) + community building
- **Trust Building** : Privacy-first + testimonials émotionnels + expert endorsements

### Pour le Designer/UX :
- **Tone** : Complice (EVERYMAN) + Humble (SAGE)
- **Key Principle** : Parent décide TOUJOURS, IA suggère
- **Avoid Patterns** : Pas de "% de charge", pas de benchmarks sociaux, pas de shame
- **Onboarding Goal** : "Wow moment" où l'IA anticipe quelque chose d'important
