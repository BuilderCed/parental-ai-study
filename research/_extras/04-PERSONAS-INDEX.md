## 🎬 Adoption Journeys (5-Phase Model)

### Phase 1: Discovery
**What triggers awareness?** (For each persona)
- Sophie: Friend mention + social proof
- Karim: Partner referral (Laure suggests)
- Nadia: Solo parent Facebook group peer recommendation
- Aminata: Diaspora WhatsApp network

### Phase 2: First Use (Days 1-7)
**Critical moment**: Onboarding + aha-moment hit or miss

### Phase 3: Couple Moment (Days 8-14) [SOPHIE & KARIM ONLY]
**If hit**: Partner sees value, defensiveness drops → premium conversion  
**If miss**: "Another app couples fight about" → abandoned

### Phase 4: Habit Formation (Weeks 2-4)
**Sophie**: Daily use (5-10 min), if value clear  
**Karim**: 3-4x/week if recognition features work  
**Nadia**: High engagement (30-45 min/week) if validated  
**Aminata**: Community bonding starts

### Phase 5: Retention/Churn (Week 5+)
**Retention drivers**:
- Sophie: Visible couple improvement + continuous innovation
- Karim: Recognition + non-judgmental feedback
- Nadia: Community + validation + psychological safety
- Aminata: Bilingual features + diaspora community

**Churn triggers**:
- Sophie: "Perfectionism amplifier" ; paywall friction
- Karim: "Feminine design" perception ; blame tone
- Nadia: Judgment tone ; expensive too soon
- Aminata: Monolingual/monocultural erasure
