## Data Accuracy & Caveats

**Pricing** : High confidence (from official pages, Feb 2026)  
**Features** : High confidence (from official pages + blogs)  
**Downloads/Users** : Medium confidence (estimates from Sensor Tower, app stores)  
**Ratings** : Medium confidence (snapshot in time, fluctuates)  
**Funding** : Medium confidence (public disclosures only, may be outdated)  
**Trends** : Medium-high confidence (multiple sources consistent)

**What's NOT in this report** :
- User retention cohorts (proprietary)
- LTV/CAC metrics (proprietary)
- Private cap tables or investor deck data
- Insider perspective on product roadmaps
- Real-time financial data

**What IS in this report** :
- Publicly available features & pricing
- App store ratings & download estimates
- Public funding announcements
- Market research from analyst firms
- Blog posts & media coverage
- Official positioning statements

## Key Metrics Explained

| Metric | Definition | Scale |
|--------|-----------|-------|
| **TAM** | Total Addressable Market (theoretical market size) | $100M - $2B |
| **DAU** | Daily Active Users | 50k - 500M |
| **Rating** | App Store / Google Play average | 1-5 stars |
| **Downloads** | Lifetime installs (est. via Sensor Tower) | 100k - 500M |
| **Conversion** | % free users → premium | 5-30% |
| **Retention (D30)** | % users active on day 30 | 10-60% |
| **CAC** | Customer acquisition cost | $5-50 |
| **LTV** | Lifetime value per customer | $20-500 |
| **Churn** | % users lost monthly | 5-30% |
| **CAGR** | Compound annual growth rate | 5-20% per segment |

## Updating This Report

**To update a competitor** :
1. Find section in 02-competitors.md (Ctrl+F competitor name)
2. Update specific fields (pricing, features, ratings, status)
3. Cross-check with official product page (update date)
4. Update sources-log.md if using new source
5. Note: Don't update summary/trends sections unless major market shift

**To add a new competitor** :
1. Identify which Tier (1-5) they belong to
2. Copy template from existing fiche
3. Fill in 10 required fields (name, URL, pricing, features, etc.)
4. Add to sources-log.md
5. Update section header count (e.g., "9 acteurs" → "10 acteurs")
6. Add to Matrice Comparative Features

**Frequency** :
- Quarterly update recommended (market moves fast)
- Annual full recheck (funding rounds, exits, new entrants)
- Spot updates as needed (major pricing change, acquisition, launch)
