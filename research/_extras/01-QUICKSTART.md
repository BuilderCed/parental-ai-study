## The Problem (1 minute)

**Charge mentale parentale** = the invisible cognitive load that 71% of mothers carry alone.

Not a task problem → already fragmented across 50 apps.  
A cognition problem → anticipation ("what's next week?") + decision-making ("what's dinner?") + equity ("why don't I see this?").

**Current solutions fail** because they :
1. Reflect status quo (still need to ask partner)
2. Require painful data entry (45+ min, then abandoned)
3. Don't change couple dynamics (partner doesn't engage)
